# Static Code Analysis — Identified Issues & Remediation Log

This document records the static analysis issues identified in `auction_system.py` using **Bandit**, **Pylint**, and **Flake8**, along with the logical bugs uncovered during inspection, prioritized by severity.

## Known Issue Table

| Issue | Type | Line(s) | Description | Fix Approach | Severity |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Insecure XML-RPC Import (B411)** | Vulnerability | 5 | Using standard `xmlrpc.client` is vulnerable to XML attacks (e.g., entity expansion, XML external entity / XXE, Billion Laughs attack). | Applied `defusedxml.xmlrpc.monkey_patch()` to replace vulnerable parsers with safe ones, and annotated import with `# nosec B411`. | **High** |
| **Jinja2 Autoescape Disabled (B701)** | Vulnerability | 65 | `Environment(autoescape=False)` disables HTML escaping, allowing Stored/Reflected Cross-Site Scripting (XSS) via auction titles (`LOT2` script injection). | Changed `autoescape=False` to `autoescape=True` so that all untrusted dynamic inputs are automatically escaped. | **High** |
| **Unescaped Markup Usage (B704)** | Vulnerability | 70 | `Markup("<span class='bidder'>" + name + "</span>")` directly concatenates untrusted bidder names into raw HTML Markup, causing XSS vulnerability. | Sanitized dynamic input using `markupsafe.escape(name)` before formatting it into the `Markup` template string. | **Medium** |
| **Lexicographical Date Comparison Bug** | Bug / Logic | 22 | String comparison `at > self.ends_at` evaluates alphabetically (`"9:30"` > `"18:00"`), improperly rejecting valid morning bids before auction close. | Parsed string dates into `datetime` objects using `datetime.strptime` for accurate chronological comparison. | **High** |
| **Self-Bidding / Shill Bidding Bug** | Bug / Logic | 24 | The seller was permitted to bid on their own auction lot (`seller_sam` bidding 4000 on LOT1), artificially inflating bids. | Added seller check `if bidder == self.seller: return False` to prohibit shill bidding. | **High** |
| **Missing Reserve Price Enforcement** | Bug / Logic | 32, 38 | `self.reserve_price` was ignored; bidders won auctions even when their bids were below reserve (`carl` winning with Rs. 0 on reserve 800). | Updated `winner()` and `final_price()` to verify `self.highest >= self.reserve_price`, returning `None` and `0.0` when reserve is not met. | **High** |
| **Minimum Bid Increment Ignored** | Bug / Logic | 24 | `amount >= self.highest` permitted bids with zero increment or less than `MIN_INCREMENT` (100) (e.g. +50 bid accepted). | Enforced `min_required = self.highest + MIN_INCREMENT` for subsequent bids, and `amount > 0` for initial bids. | **Medium** |
| **Broad Exception Raising (W0719)** | Code Smell / Reliability | 23 | Raising bare `Exception("Auction closed")` makes granular exception handling impossible for callers. | Created custom domain exception classes `AuctionError` and `AuctionClosedError`. | **Medium** |
| **Broad Exception Catching (W0718)** | Code Smell / Reliability | 50 | Catching bare `except Exception:` silences system-exiting signals, keyboard interrupts, and unrelated runtime bugs. | Replaced with specific exception types `except (AuctionClosedError, KeyError, ValueError):`. | **Medium** |
| **Undefined Attribute Outside Init (W0201)** | Code Smell / Design | 27 | `self.leader` was defined inside `placeBid` rather than `__init__`, causing `AttributeError` if accessed before any bids exist. | Implemented `leader` as a safe `@property` that reads from `self.bids[-1][0]` if bids exist, else returns `None`. | **Medium** |
| **Useless Object Inheritance (R0205)** | Code Smell / Style | 11 | Class `Auction(object)` explicitly inherits from `object`, which is redundant in Python 3. | Simplified class definition to `class Auction:`. | **Low** |
| **Unnecessary Else Blocks (R1705, R1724)** | Code Smell / Complexity | 29, 60 | Unnecessary `else` blocks after `return` and `continue` added useless indentation and cyclomatic complexity. | Removed redundant `else` branches and de-indented sequential logic. | **Low** |
| **Missing Docstrings (C0114, C0115, C0116)** | Quality / Documentation | 1, 11, 21+ | Missing module, class, and method docstrings across the entire script. | Added PEP 257 compliant docstrings explaining the purpose, parameters, and return types for all constructs. | **Low** |
| **Non-conforming Names (C0103)** | Style / Standard | 21, 37+ | Functions and methods used `camelCase` (`placeBid`, `finalPrice`, etc.) violating PEP 8 `snake_case` guidelines. | Refactored functions to `snake_case` while providing backward-compatible aliases for full compatibility. | **Low** |
| **PEP 8 Formatting & Line Length (E302, E305, E501)** | Formatting / Style | Multi | Missing two blank lines around top-level classes/functions and lines exceeding 79 characters. | Added required blank lines and wrapped long statements and docstrings to fit within 79 characters. | **Low** |
